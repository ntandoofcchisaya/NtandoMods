🚀 How to Deploy on Render

  1. Copy your Session ID from above
  2. Go to render.com and create a new Web Service
  3. Connect your GitHub fork of NtandoMods
  4. Build Command: npm install
  5. Start Command: node index.js
  6. Add Environment Variable: SESSION_ID = your copied session ID
  7. Deploy! The bot auto-connects using the session ID
